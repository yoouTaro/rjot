Specifications

What it is, what it reads, and where your notes go.

Gesture
Two taps of Shift alone, under 350 ms apart
Reads
The focused app's selected text through Accessibility; otherwise C, with your clipboard put back exactly
Keeps
One JSON file, ~/Library/Application Support/dev.rjot.rjot/notes.json
Sends
Nothing. No account, no sync, no analytics, no network
Skips
Copies a password manager marks as concealed
Runs on
macOS 11 or later, Apple silicon
Weighs
3.4 MB zipped
Built with
Rust and egui, one native binary
License
MIT, source on GitHub

Assembly

  1. 1

    Download

    Get the zip from GitHub Releases, unzip it, and move rjot.app to Applications.

  2. 2

    Open it once

    It isn't notarized yet, so right-click rjot.app and choose Open, or run xattr -dr com.apple.quarantine rjot.app.

  3. 3

    Allow Accessibility

    Click Open System Settings in rjot and switch it on. That lets it hear Shift and read the selection.

  4. 4

    Tap Shift twice

    Select something anywhere. A short pop means it's kept.
